# OmniCare AI 🏥

### AI-Powered Unified Patient Medical Record Intelligence Platform

OmniCare AI is a healthcare platform designed to address the problem of scattered patient medical histories across hospitals, laboratories, and healthcare providers. It helps organize medical documents and transform them into structured, chronological health information.

## 🎯 Problem Statement

Patient medical records are often distributed across multiple healthcare providers, making it difficult for doctors to obtain a comprehensive view of a patient's medical history.

## 💡 Solution

OmniCare AI uses AI-powered document understanding to extract clinical information from medical reports and organize authorized patient records into a unified health timeline.

## ✨ Key Features

- **Unified Health Records:** Organize medical documents in one place.
- **AI Medical Document Extraction:** Use Google Gemini to extract structured clinical information from supported documents.
- **Health Timeline:** Display medical events chronologically.
- **Patient Management:** Support registered patients and guest patient workflows.
- **Medical Record Uploads:** Upload and manage supported medical documents.
- **Doctor Portal:** Provide authorized access to relevant patient records.
- **Medical History Intelligence:** Organize diagnoses, investigations, medications, and follow-up information.
- **Secure Record Management:** Associate records with the correct patient identity and enforce access controls.

## 🛠️ Technology Stack

- **Backend:** Python, Flask
- **Database:** Supabase
- **AI:** Google Gemini API
- **Document Processing:** Python document-processing libraries
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git and GitHub

## ⚙️ Configuration

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt`.
4. Configure the required environment variables in a local `.env` file.
5. Run the Flask application using the project's configured entry point.

Required environment variables may include:

- `SECRET_KEY`
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `GEMINI_API_KEY`
- `GEMINI_MODEL`

Use the exact variable names expected by the application. Never commit API keys, credentials, real patient records, or other sensitive information.

## 🔐 Privacy and Security

OmniCare AI is intended to support the secure organization of healthcare information. Production deployment requires appropriate authentication, authorization, private file storage, database access policies, and protection of sensitive medical information.

AI-extracted information must be reviewed by qualified healthcare professionals before being used for clinical decisions.
